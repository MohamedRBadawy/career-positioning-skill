# Gap Analysis Rubric

Step 4 ranks Tier 2 gaps by impact on positioning, time to close, and
difficulty. This rubric makes those scores explicit, so rankings are
comparable across sessions instead of re-invented each time.

Treat it as a working file. Adjust the weights to the user's situation.

## Tier tests (run before scoring)

- **Tier 1: Strengths to activate.** The user already has it, verified by a
  named proof point or shipped work, not a claim. AND current demand is
  confirmed by this session's Step 3 searches, not assumed.
- **Tier 2: Gaps to close.** The market demonstrably wants it (it appears in
  at least 2 independent Step 3 sources) AND the user has no verifiable
  evidence of it yet.
- **Tier 3: Dead weight.** The user spends real time on it AND it appeared in
  no Step 3 demand signal. Name where those hours should go instead. This is
  reallocation, not criticism.

If an item fits no tier cleanly, it is not ready for analysis. Flag it as an
open question. Do not force a tier.

## Tier 2 scoring: three axes, 1 to 5 each

**A. Impact on positioning (weight x2)**

- 5: Directly unlocks the target positioning or a named income path
- 4: Strongly reinforces an existing cluster of proof points, or makes current
  assets sellable to a new segment
- 3: Broadens credibility; the market wants it, but it does not change what
  the user can charge
- 2: Nice to have; appears in postings but is rarely decisive
- 1: Marginal; mentions are declining or generic

**B. Time to close** (at the user's real available hours, as confirmed in this
session, never an optimistic default)

- 5: Under 2 weeks
- 4: 2 to 4 weeks
- 3: One 30-day block
- 2: Two 30-day blocks
- 1: More than 60 days of sustained work

**C. Difficulty** (independent of time)

- 5: Applies skills the user already has to a new surface; near-certain to land
- 4: Learnable by doing, with AI assistance
- 3: Needs structured study plus applied practice
- 2: Needs external feedback loops the user does not have yet (clients,
  reviewers, certification bodies)
- 1: Needs resources the user does not have (capital, credentials, or an
  income gap; see disqualifiers)

**Composite score:** (2 x A) + B + C. Ties break toward the higher A.
Positioning impact beats convenience.

## Hard disqualifiers (override any score)

- Anything that requires an income gap the user cannot absorb
- Anything scheduled over a fixed commitment the user named
- Any plan block that runs past the 90-day horizon. Flag it; do not include
  it silently.

## Output discipline

- Every Tier 2 entry names the exact skill, tool, or credential. Never
  "improve your skills".
- Every Tier 1 entry names the specific proof point to lead with, and why.
- The analysis ends with one sentence: the single highest-leverage action for
  the next 30 days. Pick it from the top-ranked Tier 2 gap or the strongest
  unused Tier 1 strength, whichever moves positioning sooner.

## Worked scoring example (illustrative only)

| Gap | A (x2) | B | C | Score |
|---|---|---|---|---|
| Process modelling notation | 4 (8) | 3 | 3 | 14 |
| Workflow automation platform certification | 3 (6) | 4 | 4 | 14 |
| Public case study of a shipped automation | 5 (10) | 4 | 5 | 19 |

The case study wins. It scores highest on impact and reuses work the user has
already done. The first two tie at 14 and both have A = 4 vs 3, so the
modelling notation ranks second.
